# **App Name**: AutoCommerce

## Core Features:

- Product Listing and Details: Display a catalog of available automobiles with detailed information such as specs, images, and pricing.
- Shopping Cart Management: Enable users to add, remove, and modify items in their shopping cart using Context API for state management.
- Simulated Authentication: Implement a simulated login system using localStorage to manage user sessions and protect private routes.
- Product CRUD Operations: Allow administrators to create, read, update, and delete product listings using a MockAPI for backend services.
- Search and Filtering: Enable users to search for products by name or category, with real-time filtering as they type.
- Pagination: Divide the product catalog into multiple pages for better browsing and performance.
- AI-powered tool: Implement a system using the Bootstrap grid layout for a responsive design across various devices.

## Style Guidelines:

- Primary color: Deep Blue (#1A237E) to convey trust and sophistication.
- Background color: Light Gray (#F5F5F5) for a clean and modern look.
- Accent color: Orange (#FF5722) for calls to action and highlights, providing a sense of urgency and excitement.
- Body font: 'Inter', a sans-serif font for clear and modern readability.
- Headline font: 'Space Grotesk', a sans-serif font for modern headlines.
- Use React Icons for interactive elements to provide a consistent and intuitive user experience.
- Employ Bootstrap's grid system for a responsive layout that adapts to different screen sizes.
- Incorporate subtle animations using React Toastify for notifications, providing user feedback without being intrusive.
